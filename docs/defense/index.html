The five things to be able to explain without notes
  1. Ingestion: pages, then 800-character chunks with 150 overlap that never cross a page, then vectors, then the saved index (only when complete, reused if newer than the PDF).
  2. The writer: markers, replace one block, atomic write, a failed answer is never written.
  3. The CLI: it only orders the other modules; one failed question never stops the run; exit codes 0, 1, 130.
  4. The web interface: same backend, live events (SSE), one job at a time, localhost-only plus Host and Origin checks.
  5. Honesty: 6 of 8 right, how refusals interact with the flag, what the quote check proves and does not prove.
Two things to check on your laptop before you go in

1. Your local config.json has chunk_size 500 but the committed value is 800 (59 chunks, not 98). Know which one you show.

2. Warm the models and clear old files before the live demo: see the steps in docs/KEYNOTE.md, section 3.

How to open this kit

Double-click index.html, or in VS Code right-click it and choose Open with Live Server, or run xdg-open docs/defense/index.html. No internet and no server are needed. The quiz remembers your progress in this browser only. Use the Dark / light button at the top right to change the look, and print the guide to PDF with Ctrl+P if you want a paper copy (the interactive tools are hidden when printing).
